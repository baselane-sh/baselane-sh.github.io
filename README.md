# baselane-sh.github.io

The Baselane mods gallery at the org root, https://baselane-sh.github.io/.

This repo holds no site code. Its workflow builds the gallery from [baselane-sh/mods-catalog](https://github.com/baselane-sh/mods-catalog) every hour and on each push, so the pages match https://baselane-sh.github.io/mods-catalog/. Canonical links point at the mods-catalog URL.
